# 阶段继续提示词

每个阶段都在**新会话**里开工：把下面这段贴给新会话即可。它是给执行者的交接说明——
先读计划文档自对齐，再做当前阶段，做完停下等 review，未经批准不提交。

**用法**：把 `{{阶段}}` 换成计划文档「进度」表里那一行（标注为「未开始」的下一行），其余不用改。

---

```text
继续 UCode 的 agent 能力建设，本次做【{{阶段}}】。

先读这两份，再动手：
- plans/agent-tools-and-modes.md —— 这项工作的单一事实源，看「使用方式（跨会话）」「进度」
  以及「三、分阶段方案」里对应阶段的目标、改动点、契约/DB 影响、验收标准
- AGENTS.md —— 仓库开发约定（必须遵守）

当前进度：见计划文档的「进度」表，本次做其中标注为「未开始」的下一阶段；
该阶段的测试用例见计划文档「4.3 各阶段用例」对应部分。

工作方式（重要）：
- 独立完成实现 → 自查（pnpm check 必须全绿）→ 然后【停下等我 review】。
- 未经我明确说「提交」，不要执行 git commit。
- 变更遵守仓库约定：契约先行（packages/contracts）、中文注释与文案、界面文案走 i18n、
  涉及流程状态时更新 CHANGELOG.md、测试放 __tests__/ 目录并用 node:assert/strict。
- 不确定的取舍先问我，别自行扩大范围。

请先读文档，然后用几句话复述你的实现顺序和需要我拍板的点，再开始写代码。
```

> 阶段标题、状态与提交哈希都以 [`agent-tools-and-modes.md`](./agent-tools-and-modes.md) 的「进度」表为唯一来源，
> 本文不再复制一份，避免两处不同步。
