## 三条读法

1. **代码是唯一判断依据**：文档与代码冲突时以代码为准，并把该不一致报出来。
2. **规则去 AGENTS.md，机制来 docs/**：这里不重复写法禁令（命名、注释、边界），只解释"为什么这样设计"。
3. **事实不复制**：表数、命令数、清单类"数量"一律指向代码，文档里不硬编码复制。
